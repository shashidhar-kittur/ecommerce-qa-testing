# E-Commerce Website QA Testing Project

## Project Overview

This project demonstrates manual testing and test documentation for an e-commerce web application.

## Application Tested

[SauceDemo](https://saucedemo.com)

## Testing Activities

- Test scenario design
- Test case creation
- Functional testing
- Regression testing
- Smoke testing
- Positive and negative testing
- Bug reporting
- Test execution reporting

## Modules Tested

- Login
- Product Listing
- Product Details
- Shopping Cart
- Checkout
- Logout

## Project Deliverables

- 20 Test Scenarios
- 24 Detailed Test Cases
- Bug Reports
- Test Execution Report
- Test Plan

## Tools Used

- Google Chrome
- Microsoft Excel
- Git
- GitHub
- Windows Snipping Tool
