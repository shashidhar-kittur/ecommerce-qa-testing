# E-Commerce Website Test Plan

## 1. Objective

To validate the functionality, usability, and reliability of the e-commerce website.

## 2. Scope

Testing includes:

- Login
- Product listing
- Product sorting
- Product details
- Shopping cart
- Checkout
- Logout

## 3. Testing Types

- Functional Testing
- Regression Testing
- Smoke Testing
- Positive Testing
- Negative Testing
- UI Testing

## 4. Test Environment

- Browser: Google Chrome
- Operating System: Windows
- Application: SauceDemo

## 5. Entry Criteria

- Application is accessible
- Test environment is available
- Test credentials are available

## 6. Exit Criteria

- All critical test cases executed
- Major defects documented
- Test execution report completed

## 7. Deliverables

- Test scenarios
- Test cases
- Bug reports
- Test execution report
- Test summary
